# How this list is derived, not guessed: `backend/main.py`, `backend/locations.py`,
# `backend/simulation/*.py` and `backend/ai/*.py` were walked with `ast` and

# Pinned 2026-09-28 (Stage 0). These were completely unpinned, which meant a
# deploy resolved to whatever was newest on the day and could fail on a source
# break in a file that was already working — the worst kind to debug on a free
# tier. Floors are set from what the code actually uses, deliberately loose
# enough to accept a few releases of drift, tight enough that an API this
# project depends on cannot vanish under it. Verified locally against Python
# 3.13.7; actual installed versions are noted per line.
